# SpaceSmart for macOS v1.3.0

[전체 안내로 돌아가기](../README.md)

macOS 13 이상을 지원하는 Swift/AppKit 앱입니다. Apple Silicon과 Intel용 실행 파일을 함께 빌드합니다. 사용자는 별도 Python 환경이나 API 키 없이 사용할 수 있습니다.

## 앱 설치

1. [최신 릴리스](https://github.com/kakao-workshop/spacesmart/releases/latest)에서 `SpaceSmart-Mac-1.3.0.dmg`를 받습니다.
2. `SpaceSmart.app`을 **Applications(응용 프로그램)** 폴더로 드래그합니다.
3. DMG를 추출하고 응용 프로그램 폴더의 앱을 실행합니다.
4. Bluetooth 사용을 허용합니다. 디바이스 전원을 켜고 약 10초 기다립니다.
5. **개요**에서 내 기기를 선택하고 **연결**을 누릅니다. CPU·메모리·네트워크·시간이 약 2초마다 갱신됩니다.

기기를 한 번 선택하면 다음 실행부터 해당 기기에 자동으로 연결합니다. 여러 대라면 처음에는 원하는 보드 하나만 켜서 선택하세요. 같은 보드에 다른 Mac이나 이전 개발용 브리지가 연결되어 있다면 그 연결부터 종료합니다.

현재 배포본은 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 출처를 확인하고 실행을 한 번 시도한 뒤, 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용합니다. 관리되는 Mac에서는 조직 정책을 따르세요. [Apple 안내](https://support.apple.com/en-us/102445)

## 메뉴와 사용 순서

| 메뉴 | 사용법 |
|---|---|
| 개요 | 기기 선택·연결·연결 취소, 현재 PC 사용량 확인 |
| 조명 → 직접 조절 | 전원 전환, 기본 조명 복원, 밝기·색온도 조절 |
| 조명 → 자동 조절 | 위치 프로필·학습 상태 확인, 준비 후 자동 밝기 켜기, CSV 내보내기 |
| 조명 → 연결 설정 | 리모컨 등록, 전원 상태 맞춤, 실제 동작 확인, 고급 ID·페어링 |
| 커스텀 | 카드 3개의 종류·제목·좌우 텍스트 편집 후 **변경 사항 저장** |
| AI 연동 | Claude·Codex 설치, Codex 훅 검토, 표시 시험, 연동 해제 |
| 설정 | 자동 실행, 설치 가이드, 데이터 폴더 |

**조명에서도 왼쪽 개요를 누르면 바로 돌아갑니다.** 모든 화면은 한 창에서 전환됩니다. 조명 세부 메뉴는 아래 내용을 스크롤해도 고정됩니다.

- `⌘1~5`: 개요 / 조명 / 커스텀 / AI 연동 / 설정
- `⌘,`: 설정, `⌘Q`: 앱 종료
- `⌘C / ⌘V / ⌘X / ⌘A`: 텍스트 복사·붙여넣기·잘라내기·전체 선택
- 창 닫기: 메뉴 막대에서 계속 실행. 메뉴 막대 아이콘으로 다시 열 수 있습니다.

### 커스텀 화면

CPU·메모리·저장 공간은 사용률 막대, 네트워크 RX/TX·저장 공간 여유/전체는 자동 텍스트로 표시합니다. 사용자 텍스트에서는 제목·하단 왼쪽·하단 오른쪽을 직접 입력할 수 있습니다.

메뉴를 옮겨도 작성 내용은 유지됩니다. **변경 사항 저장**을 누르면 창을 닫지 않고 완료 메시지를 보여줍니다. 연결 전에도 저장할 수 있으며, 연결 후 디바이스의 **커스텀** 탭에 전송합니다. 제목을 비우면 기본 제목을 사용합니다. 각 칸은 UTF-8 24바이트(한글 약 8자)까지 저장합니다.

### Claude Desktop · Code 탭

1. **AI 연동 → Claude 연동 설치**를 누릅니다.
2. Claude Desktop의 **Code 탭**에서 새 작업을 시작합니다.
3. 기존 세션에 반영되지 않으면 작업을 저장한 뒤 Claude를 다시 엽니다.

일반 Chat·Cowork 상태는 이 방식의 수집 대상이 아닙니다.

### Codex

1. **AI 연동 → 1. Codex 연동 설치**를 누릅니다.
2. **2. Codex 훅 검토 열기**를 누릅니다.
3. 열린 터미널에서 `/hooks`를 입력합니다.
4. `SpaceSmartAgent hook codex` 명령이 들어 있는 새 훅을 직접 검토·신뢰합니다.
5. Codex에서 새 작업을 실행해 디바이스의 **AI 작업** 화면을 확인합니다.

훅이 새로 추가되거나 변경되면 사용자 신뢰 설정이 필요합니다. 앱이 이 절차를 우회하지 않습니다. 기본 사용자 설정인 `~/.claude/settings.json`, `~/.codex/hooks.json`을 지원하며 별도 프로필 폴더는 자동 설치 대상이 아닙니다.

**Codex 표시 시험**은 연결된 디바이스에 작업 중 → 입력 대기 → 응답 완료를 각각 12초씩 표시합니다. 실제 작업 실행이나 훅 검증을 대신하는 기능은 아닙니다. 36초 후 관측된 실제 상태로 복원합니다.

### 조명과 학습

조명 기능에는 **펌웨어 v2.3 이상**이 필요합니다. [설치·학습 안내](../Arduino/docs/LIGHTBAR_KO.txt)에 따라 원래 리모컨을 등록하고 실물 동작을 확인합니다. 전원·밝기·색온도는 기록에 따른 추정값이며 조명이 회신하는 상태가 아닙니다.

위치를 고정하고 수동 조절한 전후 조도를 기록합니다. 유효 기록 20개·사용 시간 3회·밝기 3단계·예측 일관성 등을 확인한 뒤 자동 조절을 직접 켭니다. 고정 lux 목표 대신 해당 위치의 사용자 선택을 학습합니다. 앱 종료·연결 끊김·기기 재부팅 시 자동 조절은 꺼집니다. **실제 RF 제어와 현장 학습은 검증 전**입니다.

## 문제 해결·삭제

| 증상 | 확인할 내용 |
|---|---|
| 기기가 안 보임 | 보드 전원·Mac Bluetooth·다른 Mac 연결 확인 후 개요 → 다시 찾기 |
| Bluetooth 권한 거절 | 시스템 설정 → 개인정보 보호 및 보안 → Bluetooth에서 허용 후 재실행 |
| 조명 데이터가 안 옴 | 일반 연결 상태와 펌웨어 v2.3 이상 여부 확인 |
| AI 상태 미확인 | 훅 설치·Codex 신뢰·새 실제 작업 확인. 일반 대화 탭은 지원 대상 아님 |
| 자동 조절 비활성 | 실물 확인·학습 조건·켜짐 상태·신선한 센서 데이터 확인 |

업데이트할 때는 메뉴 막대에서 앱을 종료한 뒤 새 앱으로 교체합니다. AI 수집기도 갱신하려면 사용하는 앱의 연동 설치를 다시 누르세요. SpaceSmart 훅은 중복 추가하지 않습니다.

삭제할 때는 **AI 연동 → AI 연동 해제**, **설정 → Mac 로그인 시 자동 실행 해제**를 진행한 뒤 앱을 종료하고 휴지통으로 옮깁니다. 학습 기록과 백업을 함께 지우려면 설정에서 데이터 폴더를 먼저 열어 확인합니다.

데이터는 `~/Library/Application Support/SpaceSmart`에, 선택 설정은 macOS 사용자 기본 설정 `local.spacesmart.mac`에 보관됩니다. `backups`에는 원래 사용자 설정이 들어갈 수 있으므로 공유하지 마세요.

## 소스에서 빌드

Xcode Command Line Tools가 설치된 Mac에서 저장소 루트 기준으로 실행합니다.

```sh
xcode-select --install   # 이미 설치되어 있으면 생략
zsh macos/build.sh
open build/macos/SpaceSmart.app
```

기본 출력은 `build/macos/SpaceSmart.app`입니다. 경로를 바꾸려면 `zsh macos/build.sh /원하는/출력/폴더`를 사용합니다. 시스템 프레임워크만 링크하며 앱 안에 네이티브 `SpaceSmartAgent`와 설치 PDF를 포함합니다. 사용자 Mac에는 개발 도구가 필요 없습니다.

```sh
sh macos/tests/run.sh    # 실제 사용자 설정 대신 임시 폴더에서 테스트
```

문서 재생성에만 ReportLab이 필요합니다. 원본 PDF가 포함되어 있으므로 일반 앱 빌드에서는 아래 단계가 필요 없습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install reportlab
.venv/bin/python macos/make_guide.py
```

개발용 `.venv`와 빌드 결과는 Git에서 제외됩니다. 앱을 빌드한 뒤 배포 패키지를 만들 수 있습니다.

```sh
python3 macos/package_release.py
```

`dist/`에 DMG, 세 소스 폴더를 포함한 ZIP, SHA-256 목록이 생성됩니다. Git이 추적하는 파일만 소스 ZIP에 넣으므로 새 소스는 먼저 `git add`로 등록합니다. 외부 배포용 Developer ID 서명·공증은 배포자가 별도로 적용해야 합니다.

`legacy/`는 이전 Python/Swift 개발 브리지의 보존본입니다. 현재 앱과 동시에 실행하지 마세요. 현재 제품의 진입점은 `AppMain.swift`, 빌드는 `build.sh`입니다.
