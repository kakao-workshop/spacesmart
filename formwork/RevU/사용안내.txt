SpaceSmart RevU — 강화 걸쇠와 전면 정리
기준 RevT / 2026-10-31 / 단위 mm

이번 변경
1. ESP32 홀더와 배선 가이드, 고정 키의 조립 위치를 전면으로2mm 이동.
   PCB 중심(-23.5,78.55), USB는 후면. 기존09 고정 키는 형상이 같으므로 재사용.
2. 상판 조도8x8mm 창과 차광목을 우측으로2mm 이동. 창 중심(8.8,99).
   CO2 상부 슬롯과 센서 PCB 위치는 RevT와 동일.
3. 상판–하판 및 조명부–하판 걸쇠: 폭5.6→8, 몸통1.2→1.6.
   뿌리 사선 받침, 뒤쪽 변형 제한벽(간격0.8), 평평한 걸림턱 추가.
   상부 걸림턱0.45, 하부0.35. 측면 받이와 하판 슬롯도 이에 맞춰 확대.
   하부 뒤 걸쇠는 기존 정렬 기둥과 간섭하지 않도록 Y80→79.
4. 상판 내부의 기존 나사 돌출부4개 제거.
5. 상판 전면 LCD 결합 프레임의 아래 가로대 제거. 별도 원본 전면 커버는 그대로.
6. 조명부 중앙 배선 칼라의 뒤쪽 공중 가로대18mm 제거.
   Z3.5 위는 열린 형태. 좌우 다리와 바닥은 유지.

출력 파일
STL/01_main_body_black.stl — 검정 상판, 재출력
STL/03_integrated_lower_base_white.stl — 흰색 일체형 조명부, 재출력
STL/05_integrated_slot_tray_black.stl — 검정 하판, 재출력
STL/02_original_front_optional_black.stl — 기존 전면 재사용 가능
STL/09_esp_retainer_black.stl — 기존 ESP 키 재사용 가능
01/03/05는 RevU 세트로 사용.
STL은 출력 방향으로 정렬되고 바닥Z0에 놓임.
01은 후면을 베드에,03/05는 바닥을 베드에 놓는 방향.
기존 DC 슬라이딩 홀더, 전면·좌우 LED 발광벽0.8mm,134mm LED 접착 경로 유지.

걸쇠 시험과 조립
Fit_Test의 작은3부품을 먼저 출력해 끼움과 해제를 확인.
시험편은 실제 걸쇠/받이 치수를 사용하지만 지지판 외형은 간소화한 공차 확인용.
실제 유지력, PLA 탄성, 반복 조립 수명은 출력 시험 전이며 해석으로 보증하지 않음.
1. 하판에 DC 보드/센서/ESP와 배선을 조립.
2. DC는 조명부 결합 전에 후면에서 앞쪽으로 밀어 넣음.
   USB 아래 탄성 턱을 아래로 눌러 통과. V/G 선은 앞쪽 통로로 뺌.
3. 조명부 정렬핀과 하부 걸쇠4개를 맞춰 하판 결합.
4. 상판을 내려 상부 걸쇠4개 결합.
5. 상판 분리: 측면8.4x1.65mm 창에서 얇고 평평한 도구로 걸쇠를 안쪽으로 누르고 한 모서리씩 들어 해제.
6. 조명부 분리: 상판 제거 후 하판 위에서 하부 걸쇠를 안쪽으로 눌러 해제.
걸쇠 뒤의 벽은 과도하게 꺾이는 것을 제한함. 해제 시 몸통을 비틀거나 케이블을 당기지 않음.

검증
저장된 네이티브 모델의 열린 경계/비다양체 모서리/퇴화면0.
최종 조립 위치와 ESP/조도/CO2/YL105/LD2410/DC 삽입 경로 강체 간섭 발견 없음.
DC 통과 경로에서 의도적으로 눌리는 탄성 턱은 별도 취급. 케이블 형상은23mm 여유 참조 영역임.
하판의0.12mm 단면 검사에서 새로 공중 시작하는 섬 없음.
A1/0.4mm/0.12mm Fine/초층0.2mm/서포트 끔으로 실제 슬라이싱 완료.
최종 화면에 floating/cantilever 경고 없음. 예상6시간/125.73g(09 포함).
RevU_A1_0p12_support_off_checked.3mf는 한 색상으로 배치한 기하 검증용.
실제 출력은03 흰색,01/05 검정으로 나누어 출력.
슬라이싱 성공은 실물 끼움 강도와 인쇄 품질의 보증이 아니므로 시험편 확인 권장.
