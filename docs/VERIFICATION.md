# 검증 범위

기준일: 2026-11-02. 이 문서는 확인한 범위와 아직 실물 확인이 필요한 부분을 구분합니다.

## 완료한 확인

- Arduino: ESP32-S3 N16R8 설정 컴파일, 20개 GPIO와 배선 CSV 대조, 대시보드·노브·LED 시험 로직, 레이더 프레임 파싱.
- 화면: 네 가지 테마·두 방향·12개 화면 상태, 데이터 없는 화면까지 120개 렌더링 검사.
- 실제 기존 디바이스: LCD·온습도·CO₂·조도·재실, LED 기능 활성화, nRF24 칩 응답, Bluetooth와 PC 데이터 전송 확인. 시계·커스텀 화면은 사용자 확인 완료.
- macOS: Apple Silicon/Intel universal 빌드, 서명 검사, 설치·재설치·연동 해제 시 다른 설정 보존, 개인정보 필터·상태 만료, 커스텀 저장.
- v1.3 UI: 단일 창 메뉴 이동, 조명에서 개요 복귀, 단축키, 붙여넣기, 커스텀 입력 유지·저장, 미저장 종료 보호, 작은 창 스크롤, 실제 Bluetooth 재연결과 PC 사용량 갱신.
- 조명 로직: 알려진 패킷 CRC, 수신 정렬, 단계 조절·시간 제한, 명령 보호, 학습 개수·시간·밝기 조건, 위치 분리·저장, 통신 단절 시 자동 조절 중지.
- 케이스 RevU: 저장된 메시·삽입 경로·단면·Bambu A1 슬라이싱 보고서. [세부 보고서](../formwork/RevU/validation-report.json).

공개 저장소의 재구성 후에도 펌웨어 컴파일, C++/Swift 테스트, STL 재생성, macOS universal 빌드와 패키지 검사를 실행합니다.
