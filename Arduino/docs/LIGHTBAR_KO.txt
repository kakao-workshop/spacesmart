SpaceSmart 조명 제어 · 펌웨어 v2.3 / Mac 앱 1.3.0
2026-11-02

지원 범위
MJGJD01YL(기존 2.4GHz 리모컨 모델)의 전원 전환, 밝기 증감/단계 지정,
색온도 증감/단계 지정, 기본 조명 복원(약 50%, 2700K), 페어링을 지원합니다.
MJGJD02YL/1S는 프로토콜이 다릅니다. 모델을 확인하세요.
이번 코드는 프로토콜·로직·화면·빌드 검사 대상이며, 조명 미설치로 실제 RF 제어와
현장 자동 조절은 아직 검증하지 않았습니다. 설치 후 아래 순서로 확인하세요.

처음 설치
1. 기존 배선 그대로 nRF24 CE17, CSN16, SCK14, MOSI13, MISO15를 사용합니다.
   YL-105 어댑터와 nRF24 모듈의 전원 배선은 ../wiring/signal-connections.csv를 따릅니다.
   센서 위치를 고정하고 조명은 제조사 안내에 맞는 전원으로 연결합니다.
2. 보드에 v2.3을 업로드하고 Mac 앱 1.3.0을 실행하여 Bluetooth로 연결합니다.
3. Mac의 '조명 → 연결 설정' 또는 디바이스 '조명 → 조명 설정'에서 '리모컨 ID 등록'.
   60초 안에 같은 리모컨을 두 번 조작합니다. 다른 순번의 정상 패킷 두 개를 받으면
   ID를 저장하고 조명 제어를 켭니다. 주변의 다른 리모컨은 이때 조작하지 마세요.
   원래 리모컨 ID를 같이 사용하므로 기존 리모컨도 그대로 사용할 수 있습니다.
4. 현재 조명 전원 상태에 맞게 '현재 켜짐/꺼짐으로 맞춤'을 선택합니다.
   조명을 켠 뒤 '기본 조명 복원'으로 밝기·색온도의 기준 상태를 맞추세요.
5. 디바이스와 Mac에서 전원, 밝기 +/-, 따뜻/차갑게, 기본 복원을 실제 확인합니다.
   모두 정상일 때만 '실물 동작 확인 완료' / '설치 후 실제 조명 동작을 확인함' 선택.
   현재 켜짐 상태와 조도 반응도 다시 확인합니다. 자동 조절은 아직 꺼져 있습니다.

원래 리모컨이 없거나 별도 ID로 연결
Mac에서 0이 아닌 6자리 16진수 ID를 저장하고 조명 제어를 켭니다.
조명 전원을 뺐다가 연결하고 20초 안에 '새로 페어링'을 실행합니다.
디바이스에서는 '조명과 새로 연결'을 선택하고 5초 안에 한 번 더 PUSH합니다.
저장된 ID가 없으면 디바이스가 임의 ID를 생성합니다. 다른 ID로 페어링하면
원래 리모컨의 연결이 바뀝니다. 원래 리모컨으로 돌아가려면 조명 전원 재연결 후
20초 안에 원래 리모컨을 길게 누르고, 다시 리모컨 ID를 등록하세요.

디바이스 조작
노브로 '조명' 화면 → PUSH → 노브로 항목 선택 → PUSH.
밝기·색온도 항목은 PUSH 후 노브로 조절하고 PUSH 또는 K0로 편집 종료.
전원은 토글, 기본 조명은 복원 명령입니다. 설정에서 등록·상태 맞춤·검증을 합니다.
밝기는 0~15의 16단계이며 0은 최소 밝기입니다. 전원 끄기와 다릅니다.
색온도도 16단계입니다. 화면의 2700~6500K 표시는 단계의 대략적인 환산값입니다.
센서·LCD·BLE의 검증된 초기화 순서는 유지하며 부팅 시 RF 송신하지 않습니다.

중요한 상태 특성
조명은 상태/명령 ACK를 회신하지 않습니다. 앱의 접수 완료는 ESP32 접수입니다.
전원·밝기·색온도는 송신 명령과 받은 리모컨 패킷으로 추정합니다.
재부팅·무선 오류·리모컨 순번 누락 때 추정값을 미확인으로 바꿉니다.
실제 조명과 다르면 켜짐/꺼짐을 맞추고 기본 조명 또는 밝기/색온도 단계로 다시 맞추세요.
원래 리모컨 RF를 놓칠 수 있으므로 외부 조명 전원 차단 뒤에도 상태를 다시 확인합니다.
RF 채널68 / 2Mbps / CRC16 / 같은 명령 20회 반복, 반복 간격10ms입니다.
반복 송신은 메인 루프를 오래 막지 않도록 나눠 처리하며 수신도 함께 수행합니다.

조정 전후 기록
디바이스·Mac·등록한 원래 리모컨에서 조절하면 연속 조작을 한 묶음으로 기록합니다.
조정 전 최근 5개 조도값의 중앙값, 마지막 조작 뒤 4초 대기 후의 5개 값,
전후 밝기 단계·색온도 단계·전원 상태·출처·품질 플래그를 남깁니다.
마지막 조작에서 12초가 지나면 기록을 확정합니다. 학습에는 센서값이 유효하고
양쪽 모두 켜짐, 밝기 단계 확인, 색온도 동일, 전후 조도 안정인 수동 기록만 사용합니다.
자동 조절 결과는 진단용으로 기록하고 사용자 선호 학습에는 넣지 않습니다.
조도 변동이 크거나 센서 포화·미확인 상태·기기 미검증·손실 이벤트는 제외합니다.

Mac 없이 쓸 때
디바이스는 미전달 기록 32건을 NVS에 저장합니다. 가득 차면 가장 오래된 것부터 지우고
누락 건수를 표시합니다. Mac 연결 후 저장 성공 ACK를 받을 때까지 재전송합니다.
Mac은 중복 기록을 제거합니다. 이전 부팅의 정확한 시각을 모르는 기록은 보관만 하고
학습에서 제외합니다. 위치 프로필은 Mac이 관리하므로 위치를 옮긴 뒤는 새 위치를 선택하세요.

개인화 학습과 자동 조절
Mac의 '조명 → 자동 조절'에서 설치 위치 이름을 선택하거나 새 이름을 만들어 사용합니다.
데이터는 Mac에서 디바이스 UUID + 조명 ID + 위치 이름으로 나눠 저장합니다.
위치를 바꾸면 자동 조절을 끕니다. 다른 위치·다른 디바이스의 기록을 섞지 않습니다.
최근 90일의 유효 기록 중 최대 200개로 학습합니다.
최소 20개 유효 기록, 20분 이상 간격으로 나뉜 3회 사용 시간, 3개 밝기 단계가 필요합니다.
추가로 조정 한 단계당 조도 변화가 일관적인지, 기록 하나를 빼고 나머지 기록으로
그때의 사용자 선택을 예측할 수 있는지 검사합니다. 개수만 채운다고 켜지지 않습니다.
고정 lux 목표가 아니라 기록으로 조명의 상대적 기여를 추정하고, 비슷한 주변 밝기에서
사용자가 마지막으로 고른 밝기를 참고합니다. 배우지 않은 환경에는 예측을 강제하지 않습니다.
준비 완료 후 사용자가 '학습한 선호로 밝기 자동 조절'을 켜야 자동 동작합니다.
실물 동작 확인, 신선한 센서·재실 데이터, 켜진 조명, 안정된 조도, 학습한 주변 조건에서
밝기를 한 단계씩, 최소90초 간격으로 조절합니다. 색온도·전원은 자동으로 바꾸지 않습니다.
수동 조작 뒤 10분간 대기하고, 예상과 다른 조도 반응이 2회 이어지면 자동 조절을 끕니다.
연결 끊김·앱 종료·기기 재부팅 후에는 다시 직접 켜야 합니다. 학습 결과는 성능 보장이 아니며
실제 센서 위치·일광 변화·전등 방향에 따라 새 위치로 학습이 필요할 수 있습니다.
